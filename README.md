# Regression Analysis Projects

Two regression and classification analysis projects, each from a different statistics course.

## album-sales-regression-analysis/

Multiple regression analysis of what drives U.S. music album sales (2000-2009), examining album-related, economy-related, and technology-related factors (record label, genre, internet usage rate, unemployment rate, etc.). Key finding: internet usage rate and record label were significant predictors of units sold, with Warner Music Group outperforming Sony and Universal. Group project for ST 625 (A Second Course in Statistics: Regression Analysis).

## student-dropout-prediction/

Predicts student dropout risk using logistic regression, a classification tree, PCA, and k-means clustering on a student outcomes dataset (academic, financial, and demographic factors). The logistic regression model achieved an AUC of 0.87 and 84.7% accuracy; tuition payment status, scholarship holding, and academic performance were the strongest predictors. Final project for ST 635, with Isabella Marashi, Kubra Abbasova, and Amgalan Tseveengerel.

## Tech stack

R (regression, ANOVA, chi-square, classification trees, PCA, k-means clustering), SAS output tables
