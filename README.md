# Regression Analysis Projects

Two regression and classification analysis projects, each in its own folder.

## album-sales-regression-analysis/

Multiple regression analysis of what drives U.S. music album sales (2000-2009), examining album-related, economy-related, and technology-related factors (record label, genre, internet usage rate, unemployment rate, etc.). Key finding: internet usage rate and record label were significant predictors of units sold, with Warner Music Group outperforming Sony and Universal.

## student-dropout-prediction/

Analysis of a student outcomes dataset (Graduate / Dropout / Enrolled), examining how admission grade, age, daytime vs. evening attendance, unemployment rate, and inflation rate relate to student outcomes, using binary and multinomial logistic regression, ANOVA, and chi-square tests. With H. Buser and V. Nagaraj.

## Tech stack

R (regression, ANOVA, chi-square, multinomial logistic regression), SAS output tables
